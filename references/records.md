# Records and full-text retrieval

- Keep one ID per identifiable source or distinct version. Keep amending acts, consolidated or point-in-time texts, translations, and genuinely distinct manifestations linked instead of merging them blindly. Use legislation identifiers, DOI, jurisdiction, language and version together. Similar titles trigger review.
- Before downloading, compare the staged and formal attachment inventories. Prefer authorized publisher PDF or official complete HTML, then lawful repository copies, author manuscripts, transcriptions and archive scans. Retain relevant source media in their original format. Retry only through reasonable and lawful access routes. Record subscription, archival restrictions, timeout or identity uncertainty; avoid access-control bypass or private inputs to public services.
- Verify original title, identity, version, provenance and body. For PDF, compare pagination, contents, first and last substantive pages and appendices; for HTML, check actual body, section sequence and pagination; for scans or media, manually inspect required pages, duration or content boundary. A successful HTTP response or matching hash is insufficient. Populate `verification-evidence.csv` using fields in [schemas](../assets/v2-schemas.json). Preserve a separate source verification status.
- For unsaved records use `fulltext-review.csv` with `id,access_status,evidence_url,reason,checked_on`. Stable access status codes are `saved_pdf`, `saved_html`, `saved_other`, `online_full`, `partial`, `abstract`, `subscription`, `archive_lead`, `unverified`. Local statuses come from actually mapped files and matching body evidence. The first three require complete verified bodies. Raw reason text is preserved; optional user-facing translations belong in presentation settings.
- Custom profiles use `profile-classification.csv` with `id,primary_category,themes,settings,theme_settings,evidence,publication_date,remarks`. Multi-values use `|`; theme/dimension associations use `design=scope1|scope2;review=scope1`. Keep codes stable between locales. For `profile-search.csv` use `theme,setting,status,evidence`, with an empty setting for theme-wide checks, and `executed` or `blocked`.
- Put source identities in `country-sources.csv`, searches in `search-log.csv`, citations in `citation-chain.csv`, and continuation work in `coverage-notes.md`. The Excel catalogue counts individual records. The pending sheet contains issues for those records. Generic coverage gaps, source directories and procedural logs are kept separate.
- Before publishing, check human edits and carry them back to staging metadata. The packager verifies relative attachment links and inventories, flags matching file bytes and retains unknown copies for review. It refuses to publish unresolved orphan content. Originals, publication files and backend together form the formal delivery directory. Use one stable output path for each jurisdiction/profile pair.
